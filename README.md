# Смета за 5 минут

Веб-приложение для быстрого составления сметы или коммерческого предложения с сохранением в PDF.

Для кого:
- предприниматели — подготовить коммерческое предложение клиенту;
- офисные сотрудники — составить смету закупки или расчёт расходов для руководителя.

## Файлы приложения

Планируемая структура (файлы приложения пока не созданы):
- `index.html` — структура страницы, поля сметы и кнопки действий;
- `styles.css` — оформление и удобное отображение на компьютере и телефоне;
- `script.js` — расчёт сумм и логика подготовки документа к сохранению в PDF.

Приложение использует обычные HTML, CSS и JavaScript, без npm, фреймворков и внешних ресурсов. Данные пользователя остаются в браузере и не отправляются в интернет.

## Как открыть

После создания файлов приложения откройте `index.html` двойным щелчком. Установка и запуск сервера не нужны.

## Как проверить

После реализации расчёта добавьте две позиции:
1. Количество: `2`, цена: `15 000 ₸`. Сумма: `30 000 ₸`.
2. Количество: `1`, цена: `8 000 ₸`. Сумма: `8 000 ₸`.

Ожидаемый итог: **2 × 15 000 + 1 × 8 000 = 38 000 ₸**.
